Sobre o VanishCam

VanishCam é uma ferramenta web independente, inspirada no conceito e na interface do fSpy original criado por Per Gantelius (https://stuffmatic.com). Não possui afiliação direta nem compartilha código com o projeto original.

Código-fonte do VanishCam

https://github.com/dinthclex/vanishCam

Versão para embutir em outro app

Uma versão do VanishCam preparada para ser usada como uma tela dentro de outro aplicativo JavaScript (passando a foto direto, sem precisar salvar/abrir arquivos) — ver README-embed.md dentro do pacote para a API completa (vanishCamMount(), vanishCamLoadImage(), vanishCamGetCamProps() etc.).

O que é o VanishCam?

VanishCam calcula a posição, orientação e o campo de visão da câmera usada para tirar uma foto, a partir de linhas que você desenha sobre ela (retas que, no mundo real, são paralelas entre si — por exemplo, as bordas de uma parede ou o batente de uma porta). Essa técnica é chamada de "calibração por pontos de fuga".

Conceitos

Ponto de fuga — na foto, é o ponto para onde parecem convergir retas que, no mundo real, são paralelas a um dos 3 eixos (x, y ou z). Cada eixo de calibração (1, 2, e o 3º auxiliar) é definido por um PAR de linhas cujas 4 extremidades você posiciona sobre bordas reais da foto; o ponto de fuga é a interseção desse par.

Ponto principal — o centro óptico da imagem, projetado sobre ela (por onde passa o eixo de visada da câmera). Pode ser o ponto médio da imagem, um ponto escolhido manualmente, ou calculado como o ortocentro dos 3 pontos de fuga (quando os 3 eixos do mundo são mutuamente perpendiculares).

Distância de referência — como a foto sozinha não diz a escala real da cena, você pode informar que um segmento, medido ao longo de um dos eixos, tem um comprimento real conhecido (ex.: "essa porta mede 2 metros"), para que posição da câmera e demais medidas saiam em unidades reais em vez de uma escala arbitrária.

Modo retângulo — quando ligado, os pares de linha dos eixos 1 e 2 compartilham 4 cantos (como as bordas de uma parede retangular vista em perspectiva), em vez de 2 pares de linha independentes.

Guias 3D — desenham, sobre a imagem já calibrada, uma caixa, grades ou o canto de um cubo alinhados com os 3 eixos do mundo — úteis para conferir visualmente se a calibração está correta.

Dicas de uso

Arraste qualquer bolinha para reposicioná-la. Segure o botão do meio do mouse para mover a imagem (pan) e use a roda para zoom. Ctrl+clique numa extremidade de linha trava/destrava só ela; Ctrl+clique no botão "Travar" (🔒) trava/destrava as 4 de um eixo de uma vez (a tecla pode ser trocada em Arquivo > Atalhos). Ctrl+Z desfaz, Ctrl+Y refaz. Quando 2 bolinhas ficam sobrepostas, segure e solte Ctrl (ou use as setas do teclado) sobre elas para alternar qual fica "na frente".

Estas 2 combinações usam o MESMO par de linhas auxiliares do 3º eixo de fuga (o mesmo par salvo no projeto) — só muda o que é mostrado/editável:

Explicador visual

Ative o botão abaixo e passe o mouse sobre qualquer elemento da imagem principal — uma seta aparece apontando para ele, com o nome e uma breve explicação do que ele é. Clicar/ arrastar fica desligado enquanto o explicador está ativo; desative-o para voltar a editar a calibração normalmente.
