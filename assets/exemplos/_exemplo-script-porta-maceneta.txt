Exemplo de Script — "Porta com Maçaneta" (duplo clique abre/fecha)
====================================================================

[13/09/2026] Este NÃO é um arquivo carregado pelo app (não é um
`.model.js`/`.instance.js` de verdade — repare na extensão `.txt`). É só
TEXTO PRONTO PRA COLAR no componente "Script" de uma PORTA com a variante
`comManeneta: true` (a que tem uma maçaneta de verdade na malha 3D — ver
`buildDoorOrWindowMesh` em js/engine3d.js), pelo editor de componentes 2D
já existente ("🧩 Editar componentes…" no painel da porta) ou pelo painel
"Propriedades e Scripts" do 3D — ambos editam a MESMA "folha de código"
(`entity.components[].code`, ver js/components.js).

IMPORTANTE — LEIA ANTES DE ACHAR QUE FALTA ALGUMA COISA AQUI
--------------------------------------------------------------
Este script é EXATAMENTE A MESMA LÓGICA do
`_exemplo-script-porta-automatica.txt` (o script de porta "normal", sem
maçaneta) — alterna `obj.anguloAbertura` entre 0 e 90 no duplo clique, e
mais nada. Ele não tem, e NÃO PRECISA TER, nenhuma linha extra de código
pra fazer a maçaneta girar.

Por quê: a animação da MAÇANETA em si (o giro rápido de ~45° no cabo,
"destrancando", que acontece no exato instante do duplo clique e volta
sozinha à posição neutra em ~250ms) é feita inteiramente pelo MOTOR 3D
(`Engine3D._updateDoorAnimations`, js/engine3d.js), e não pelo Script —
o motor detecta sozinho toda vez que o ALVO de `anguloAbertura` muda
(não importa QUEM mudou: este script, outro script diferente, ou até
uma alteração manual) e dispara o giro da maçaneta automaticamente,
contanto que a porta tenha sido criada com `comManeneta: true` (e por
consequência tenha `el._doorManetaMesh` montado). Ou seja: o Script aqui
só decide QUANDO abrir/fechar a porta (o "o quê"); a maçaneta reage
sozinha a essa decisão (o "como" da animação dela), do mesmo jeito que a
folha da porta já reagia antes desta rodada — copiar este arquivo pra
uma porta SEM `comManeneta` funciona igual (só não existe maçaneta pra
girar), e colar o script "automático" de sempre numa porta COM
`comManeneta` também funciona igual (a maçaneta gira do mesmo jeito,
porque quem dispara o giro é o motor observando `anguloAbertura`, não o
texto deste script específico).

Se um dia você quiser MUDAR como a maçaneta se move (ângulo do giro,
duração, sentido), o lugar certo é `_updateDoorAnimations` em
js/engine3d.js (bloco comentado "[13/09/2026] NOVO — animação da
MAÇANETA"), não este arquivo.

COMO USAR
---------
1. [18/09/2026] `comManeneta: true` agora é o PADRÃO de toda porta nova
   criada pela ferramenta "Porta" (ver `js/mapping.js` `addDoor`) — ou seja,
   basta criar/selecionar qualquer porta normal. Só é preciso "marcar o
   campo manualmente" numa porta bem antiga (criada antes desta mudança),
   que pode ter ficado sem o campo.
2. Selecione a porta no mapa 2D (ou mire nela no 3D).
3. Abra "🧩 Editar componentes…" → "➕ Adicionar Componente" → "Script".
4. Apague o código de exemplo que vier ("Em branco") e cole TUDO daqui pra
   baixo (a partir de "function Start() {").
5. Adicione TAMBÉM um componente "Gatilho de Evento" (EventTrigger) na
   mesma porta, com evento "Ao Clicar Duas Vezes" (onDoubleClick) → ação
   apontando pro Script acima → método `aoClicarDuasVezes`.
6. Entre em "Ver em 3D", mire na porta e dê duplo clique nela: a maçaneta
   gira rapidinho (~250ms) e, junto/logo em seguida, a folha abre suavemente
   (~500ms); duplo clique de novo, a maçaneta gira de novo e a folha fecha.

--------------------------- CÓDIGO (copie a partir daqui) ---------------------------

/**
 * Start é chamada antes do primeiro quadro (uma vez, ao iniciar o objeto).
 */
function Start() {
  // Garante um estado inicial coerente (porta fechada, sem animação em
  // curso) mesmo se `anguloAbertura` nunca tiver sido definido antes.
  // A maçaneta não precisa de nenhum estado inicial próprio aqui — ela só
  // existe (referência guardada pelo motor em `this._doorRuntime`, não em
  // `obj`) se a porta foi criada com `obj.comManeneta = true`, e o motor
  // cuida do resto sozinho.
  if (obj.anguloAbertura === undefined) obj.anguloAbertura = obj.aberta ? 90 : 0;
}

/**
 * Update é chamada uma vez por quadro (a cada frame).
 */
function Update() {
  // Nada por quadro neste exemplo — tanto a animação suave da folha quanto
  // a animação de giro da maçaneta (quando existir) já são feitas pelo
  // motor 3D sozinho (Engine3D._updateDoorAnimations), só olhando o VALOR
  // de obj.anguloAbertura definido abaixo em aoClicarDuasVezes().
}

// Debounce: evita que um duplo clique durante a animação em curso dispare
// uma 2ª troca antes da 1ª terminar visualmente. A duração agora VARIA (ver
// abaixo), então o debounce é recalculado a cada chamada.
var _debounceAte = 0;

/**
 * [18/09/2026] NOVO — "a velocidade com que se dá os dois cliques deve
 * influenciar na velocidade com que a porta abre" (a MAÇANETA continua com
 * sua própria animação fixa de ~250ms, independente disso — só a FOLHA da
 * porta varia de velocidade). `view3d` (5º parâmetro disponível pra todo
 * Script) expõe `_ultimoIntervaloDuploCliqueMs`: o intervalo real (ms)
 * entre os 2 cliques do duplo clique mais recente. Cliques bem próximos
 * (rápidos) → porta abre rápido; mais espaçados → abre mais devagar.
 */
function _calcularVelocidadeGrausPorSeg() {
  var intervaloMs = (typeof view3d !== 'undefined' && view3d && typeof view3d._ultimoIntervaloDuploCliqueMs === 'number')
    ? view3d._ultimoIntervaloDuploCliqueMs
    : 300; // fallback (velocidade padrão de sempre, ~90°/0,5s = 180°/s)
  var MS_MIN = 100, MS_MAX = 600;
  var t = (Math.max(MS_MIN, Math.min(MS_MAX, intervaloMs)) - MS_MIN) / (MS_MAX - MS_MIN); // 0 (rápido) .. 1 (devagar)
  var DEG_PER_SEC_RAPIDO = 90 / 0.25; // clique duplo bem rápido (~100ms) -> abre em ~0,25s
  var DEG_PER_SEC_LENTO = 90 / 0.8;   // clique duplo mais devagar (~600ms) -> abre em ~0,8s
  return DEG_PER_SEC_RAPIDO + (DEG_PER_SEC_LENTO - DEG_PER_SEC_RAPIDO) * t;
}

/**
 * Chamada pelo Gatilho de Evento "Ao Clicar Duas Vezes" (onDoubleClick) —
 * alterna a porta entre aberta (90°) e fechada (0°), na velocidade
 * calculada acima (`obj._velocidadeGrausPorSeg`, campo TRANSIENTE que
 * `Engine3D._updateDoorAnimations` lê, se presente). A maçaneta (se
 * `comManeneta:true`) continua girando sozinha, no seu próprio ritmo fixo,
 * no exato instante em que esta função muda `obj.anguloAbertura` — nenhuma
 * linha extra necessária aqui pra ela.
 */
function aoClicarDuasVezes() {
  var agora = Date.now();
  if (agora < _debounceAte) return; // animação anterior ainda em curso — ignora
  var velocidade = _calcularVelocidadeGrausPorSeg();
  obj._velocidadeGrausPorSeg = velocidade;
  _debounceAte = agora + Math.round((90 / velocidade) * 1000) + 50; // duração real desta animação + folga
  var estaAberta = (obj.anguloAbertura || 0) > 45;
  obj.anguloAbertura = estaAberta ? 0 : 90;
}
